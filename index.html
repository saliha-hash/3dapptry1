Vernier Caliper Formula
Reading = Main Scale Reading + (Vernier Coincidence × Least Count)

Least Count = Value of 1 main-scale division ÷ Number of Vernier divisions

Example: Main scale = 12 mm, Vernier coincidence = 4, least count = 0.1 mm.
Reading = 12 + (4 × 0.1) = 12.4 mm.

This example is a calculation, not a live measurement of the 3D model.
